= Gradle Scala Cross-Compile Example

This example cross-compiles Scala to https://www.scala-js.org/[Scala.js],
https://scala-native.org/[Scala Native], and the JVM with https://gradle.org/[Gradle]
and https://github.com/dubinsky/scalajs-gradle[scalajs-gradle].

It is inspired by https://github.com/scala-js/scalajs-cross-compile-example[scalajs-cross-compile-example].

`settings.gradle` applies `org.podval.tools.scala.settings` and calls `scalaBackend.includeBackendProjects()`.
That includes `core/js`, `core/jvm`, `core/native`, `core/shared`, and `core/js-native`.
Project names can still be changed after that include.

`core/build.gradle` applies the project plugin and sets the Scala version.
Each backend build script adds only the test frameworks it runs, and configures `link` or `run`.
The plugin adds the backend libraries, compiler plugins, and linker.

`more` is a separate Scala.js project.
`more/gradle.properties` sets `org.podval.tools.backend` to `Scala.js`.
A value in `build.gradle` would be too late.
